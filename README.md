# Multi-Agent Debate System

A multi-agent debate system built with **CrewAI**. This project simulates a structured debate on any given topic, where five specialized AI agents (Scientist, Skeptic, Pragmatist, Ethicist, Moderator) contribute their unique perspectives and finally synthesize a balanced conclusion.

## Agents and Their Roles

| Agent       | Role                                                                 |
|-------------|----------------------------------------------------------------------|
| **Scientist**   | Provides evidence-based arguments using scientific research.        |
| **Skeptic**     | Challenges assumptions and identifies weaknesses.                    |
| **Pragmatist**  | Focuses on practical implications, costs, and feasibility.           |
| **Ethicist**    | Evaluates ethical and societal impacts.                              |
| **Moderator**   | Summarizes all perspectives and delivers a balanced conclusion.      |
